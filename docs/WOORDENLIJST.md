# SoundScout Woordenlijst (aanzet — testronde 2)

Eerste aanzet voor de definitielijst die Bert voorstelde (week-3-testnotitie): één
vaste term per begrip, consistent in app, docs en communicatie. **Regels**: neutrale
taal voor alle leeftijden (geen kindertaal), "docent" (nooit juf/meester), Engelse
DAW-termen alleen waar ze ingeburgerd zijn.

> Status: concept. Bert vult aan/schrapt; daarna is dit de bron voor alle teksten
> (i18n, handleiding, landingspagina, leskaarten).

## Rollen & plekken

| Term | Betekenis | Niet gebruiken |
|---|---|---|
| **docent** | De leerkracht/muziekdocent die klassen beheert | juf, meester, leraar |
| **leerling** | De maker; werkt zonder account | kind, speler, student |
| **klas** | Groep leerlingen onder één docent, met eigen klascode | groep (als synoniem) |
| **kaart** | Overzichtsscherm met locaties van een thema | map, wereldkaart |
| **locatie** | Plek op de kaart waar je geluiden verzamelt | scène, level |
| **studio** | Het compositiescherm (tijdlijn + bibliotheek) | editor, werkplaats |
| **podium** | Presentatie- en feedbackscherm ("Het Podium") | stage (NL-teksten) |

## Codes

| Term | Vorm | Betekenis |
|---|---|---|
| **klascode** | 4 cijfers | Toegang tot de actieve opdracht van een klas |
| **bewaarcode** | 6 tekens | Persoonlijke code om je compositie terug te vinden (en feedback te zien) |
| **luistercode** | 8 tekens | Alleen-luisteren-link/code voor gedeeld werk (share/template/praatplaat) |

## Opdrachten & lesmateriaal

| Term | Betekenis |
|---|---|
| **opdracht** | Wat de docent per klas klaarzet (vrij / praatplaat / storyboard / template) |
| **opdrachtkaart** | Korte instructiekaart (titel + bullets) die de leerling vóór het starten ziet |
| **leskaart** | Kant-en-klaar lespakket: opdracht-type + bron + opdrachtkaart + lesinfo |
| **praatplaat** | Gedeelde klas-afbeelding waarop elke leerling zijn compositie een plek geeft |
| **storyboard** | Verhaal van meerdere scènes dat de leerling verklankt ("Verhaal in beeld") |
| **template** | Door de docent voorgebouwde compositie als startpunt |
| **thema** | Werelden met locaties + geluiden (De Stad, Winterspelen, …) |

## Muziek & studio

| Term | Betekenis | Opmerking |
|---|---|---|
| **geluid / sample** | Eén opgenomen klank uit een locatie | "geluid" in leerling-teksten; "sample" mag in docent/technische context |
| **recorder** | De verzamelbalk (6 vakjes) op een locatie | geen "microfoon" — er wordt niets opgenomen |
| **bibliotheek** | Verzamelde geluiden in de studio | |
| **tijdlijn** | Het raster waarop je componeert | timeline (code), tijdlijn (UI) |
| **spoor** | Eén horizontale laag van de tijdlijn (max 12) | track alleen in code |
| **blokje / clip** | Eén geplaatst geluid op een spoor | "blokje" in leerling-teksten, "clip" in docent/technische context |
| **maat** | 4 tellen; de liniaal telt in maten (16–64) | |
| **sectie** | Gekleurd deel van de tijdlijn (vorm: A/B/…) — via de vlag-knop | |
| **sectie-loop** | Eén sectie herhalen tijdens het oefenen | werkt pas nadat er een sectie is |
| **solo** | Alleen dít spoor horen (koptelefoon-icoon) | |
| **compositie** | Het muziekstuk van de leerling | liedje, song |

## Feedback

| Term | Betekenis |
|---|---|
| **feedback** | Reactie van de docent: sticker + 1–3 sterren + tekstje |
| **peer feedback** | Leerlingen beoordelen elkaars werk anoniem (sterren per criterium) |
| **feedbackkaart** | Set criteria/complimenten die de docent instelt voor peer feedback |
| **compliment** | Eén gekozen criterium-chip van een klasgenoot |
| **inzending** | Compositie die via de klascode bij de docent is ingeleverd |
| **presenteren** | Klassikaal afspelen op het digibord (presentatiemodus) |

## Twijfelgevallen — voor Bert om te beslissen

- **"blokje" vs "clip"** in leerling-teksten: nu gemengd; voorstel = blokje.
- **"Peer feedback"** (Engels) vs "klasgenoten-feedback": nu Peer feedback (jouw keuze 16-7).
- **"praatplaat"** heet richting leerlingen soms "bij een afbeelding" — één noemer kiezen?
- **"inleveren" vs "opslaan"**: de leerling klikt "Opslaan" en levert daarmee (in een klas-sessie) automatisch in — benoemen we dat verschil ergens expliciet?
