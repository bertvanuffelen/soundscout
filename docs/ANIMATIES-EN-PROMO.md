## Promotievideo — concept + script (~70 sec)

**Concept: "De muziek die je hoort, is door de app gemaakt."** De soundtrack
ís een SoundScout-compositie die je hoort ontstaan. Alles schermopnames +
huisstijl-animatielagen — **geen gefilmde kinderen nodig (AVG-proof, net als
de app)**.

| Tijd | Beeld | Audio |
|---|---|---|
| 0-5s | Zwart. Dan: een tablet "vangt" één vogelgeluid op de boerderij-locatie | Stilte → één geluid + zachte "ping" |
| 5-15s | Kaart → locaties → hotspots pulseren, recorder vult zich (2/6 … 6/6) | Elk gevangen geluid komt in de mix |
| 15-30s | Studio: slepen, knippen, loop aan — de compositie groeit zichtbaar én hoorbaar | De beat ontstaat laag voor laag |
| 30-40s | Docent zet klascode op het digibord; dashboard stroomt vol inzendingen | Compositie speelt door |
| 40-52s | Digibord: presentatiemodus/praatplaat, klas luistert; sticker + sterren verschijnen; beoordelings-sterren vliegen | Muziek + subtiele UI-geluidjes |
| 52-62s | Thuis: kind voert bewaarcode in → "Feedback van je docent" → banner | Muziek zwelt naar het einde |
| 62-70s | Titels: *Geen leerlingaccounts · Klaar voor het digibord · Gratis* → logo + **soundscout.nl** | Slotakkoord van de klascompositie |

Voice-over optioneel; één zin volstaat: *"SoundScout — muziek componeren met
je hele klas."* Uitwerking (shotlist + assets) in een aparte sessie.
