Privacy statement

Last updated: 24 October 2026. The Dutch version is leading.

In short

  • Students have no account. In class they work anonymously with a random nickname.
  • We never ask students for an email address, password or last name.
  • A teacher can set up student codes. A code belongs to one child and gives it a fixed nickname. The real name stays on paper with the teacher only, never in SoundScout.
  • No cookies, no tracking, no ads. We only count anonymously how often the app is used.
  • Submitted work is deleted automatically after one school year.
  • When a school uses SoundScout, the school is the controller and SoundScout is the processor. A data processing agreement is available on request.

1. Who is responsible?

SoundScout is a free music app for primary schools, made by Bert van Uffelen (UFB Productions, Dutch Chamber of Commerce 55237029). Contact: hello@soundscout.nl.

  • In class (students use their teacher's class code or student code): the school is the data controller. SoundScout only processes the data on behalf of the school. Schools can request a data processing agreement via hello@soundscout.nl.
  • Outside class (someone saves music online or creates a listening link) and for teacher accounts: SoundScout is the data controller.

2. What data do we process?

Students in class

  • The composition (which sounds, where on the timeline) and the name the student gives the music.
  • A random nickname, like "Singing Seal". It stays the same for the same submission. With a student code, the nickname stays the same all school year.
  • For a picture assignment (praatplaat): the spot on the picture.
  • Teacher feedback (a sticker, a level and an optional short text) and anonymous stars from classmates.
  • A save code, so the student can find the work again later.
  • With a student code (optional, set up by the teacher): the code (for example ABC-1234), the fixed nickname, the expiry date, the moment the code was last used and which submissions belong to it. No real name is stored in SoundScout. Only the teacher knows who has which code, by writing the name on the paper card.

Outside class

  • With "Save": the soundscape with an automatic nickname. The student does not type a name.
  • With a listening link: the composition and the name entered.

Teachers

  • Email address, display name and (encrypted) password.
  • Classes (name and class code), assignments, lesson cards, templates and feedback given.

Technical

  • Like any website, our hosting and database keep technical logs, including IP addresses. We only use them for security and fixing problems.
  • When logging in with a student code, continuing work and linking a submission, we keep the IP address briefly to stop people guessing codes: after too many failed attempts from one network, that network is blocked for a while.
  • An anonymous count per day of, for example, how often the app is started or a composition is submitted. No IP address, cookies or other personal data. The browser setting "Do Not Track" is respected.

SoundScout does not use the microphone or camera. Nothing is recorded.

3. What do we use the data for?

  • So students can make music, hand it in and continue later, with a student code also on another device.
  • So teachers can listen to, present and give feedback on submissions.
  • To keep the service secure and fix problems.

We do not use the data for advertising, profiling or sale. In class, the school determines the legal basis (usually its educational task). For teacher accounts and for saving online yourself, the basis is your use of the service; for technical logs it is our legitimate interest in a secure service.

5. Who has access?

  • The teacher of the class sees the submissions of their class, with nickname. With student codes, the teacher sees per code the nickname, when the code was last used and how much work belongs to it.
  • Classmates can hear classmates' music when giving stars, without a name.
  • Anyone with a link or code. If a teacher shares a class album or picture board, anyone with that link can listen to the music, with nickname and class name. With a save code or save link, someone can open and change the work, so only share it at home. A student code is as personal as a password: whoever has it can log in as that child. Keep the card safe and do not share the code.
  • Our processors, who only store or send the data for us:
    • Supabase: database and login, servers in Ireland (EU), with Amazon Web Services and Cloudflare as subprocessors.
    • Strato: website hosting and sending email for teacher accounts, Germany.
    • EmailJS: only if you use the "Need help or found a bug?" form; your message then reaches us via EmailJS.
  • YouTube: only if you open the explainer videos. The preview images and videos then come from YouTube; the videos play via the privacy-friendly "youtube-nocookie" version and only after you click play.

We do not sell data and do not share it with other parties.

6. Cookies and tracking

SoundScout sets no cookies and uses no trackers, analytics services or ad networks. Fonts and images come from soundscout.nl itself (except the YouTube previews for the explainer videos). In your browser's storage we only keep what the app needs: your music, language choice, save codes, the work you are doing now (at most 12 hours) and, for teachers, the login session.

7. Security

  • All connections are encrypted (https).
  • Students have no account; they work with codes. Submitted work can only be edited with a secret that only their own device has.
  • The database shows teachers only their own classes and limits how often codes can be requested per minute.
  • Student codes have over 138 million possibilities and are generated randomly. After too many failed attempts from one network, that network is blocked for a while. The teacher can turn off or replace a lost or misused code; the nickname and the work then stay with that child.
  • Teachers choose a password of at least 8 characters with letters and numbers.
  • Teachers: log out on a shared device, such as the interactive whiteboard.

8. Your rights

  • Students and parents: work submitted in class is handled through the school. The teacher can view and delete submissions. Work you saved online yourself is deleted on request: email us the save code. A teacher can delete or replace a student code.
  • Teachers: you can view, correct or delete your data via hello@soundscout.nl.
  • If you disagree with how we handle data, please tell us. You can also file a complaint with the Dutch Data Protection Authority (Autoriteit Persoonsgegevens).

9. Changes

If anything changes in how SoundScout handles data, we update this page and the date at the top. For major changes we inform teachers who have an account.
